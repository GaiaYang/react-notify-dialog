# daisyUI Notifier 皮膚（範例）

此目錄**不屬於** `notify` 核心，僅供示範與複製。

## 使用

```tsx
import { Notifier } from "@/notify";
import { daisyui } from "@/examples/notify-daisyui";

<Notifier components={daisyui} />
```

## 複製到自己的專案

1. 複製整個 `notify-daisyui` 資料夾
2. 依你的路徑調整 `@/dialog`、`@/notify` import
3. 確認專案已安裝 [DaisyUI](https://daisyui.com/docs/install/)
